A few design notes:

  • The --production / --staging / --dev filter flags still work — they hide entire sites with no matching envs
  • The site ID is shown dimmed so it's visible but doesn't compete with the name
  • active / inactive status shown per environment, not per site
  • env list stays as a flat table (it's already one row per env) but gets the same grouped-by-site sort order and a site name column
