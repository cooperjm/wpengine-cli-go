How should wpengine check display results?

The current default is very verbose. Which approach feels right?

A

Summary table as the default (current --minimal)

Show a compact table of all results once scanning is done. Add a --verbose flag for the full per-env detail boxes. Most useful when checking many environments.

wpengine check --all-envs
● Scanning 6 environments... ████████████████ done
EnvironmentTypeWordPressPluginsThemesStatus

acme-stagingSTG6.7.1 avail52Updates pending

globex-wpPRODUp-to-date00Up-to-date
Summary: 6 environments | 3 Up-to-date | 2 Updates pending | 1 Error
B

Live streaming results with a final summary

Keep printing each result as it comes in (good for seeing progress on slow connections), but make each result a compact single line instead of a full box. Print the summary table at the end.

wpengine check --all-envs
● Scanning 6 environments (concurrency: 10)...
✔ acme-dev DEV — All up-to-date
✔ globex-wp PROD — All up-to-date
⚠ acme-production PROD — 3 plugin updates
⚠ acme-staging STG — WP core + 5 plugins + 2 themes
✖ broken-site STG — SSH connection failed
— summary table follows —
C

Keep verbose boxes as default, improve readability

Keep the current per-environment boxes, but tighten the layout and add a collapsible plugin/theme list. Best if you often want to see exactly which plugins need updates without a second command.

wpengine check acme-production
acme-production PROD

• woocommerce 8.3.1 → 8.4.0 [active]
